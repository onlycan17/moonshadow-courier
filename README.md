# 월영전령: 심연의 기록

**월영전령: 심연의 기록**(Moonshadow Courier: Chronicle of the Abyss)은 달빛 도시와 심연의
던전을 오가며 표창 전령을 성장시키는 로컬 싱글 플레이 횡스크롤 웹 액션 RPG입니다.

별도 계정 서버나 게임 설치 프로그램 없이 브라우저에서 실행됩니다. 캐릭터 생성부터 전직,
사냥, 장비와 스킬 성장, 보스 원정, 비전투 점프 맵까지 하나의 저장 슬롯에서 이어서 플레이할
수 있습니다.

> 현재 버전: `0.1.0`
>
> 최종 제품 계약: [`docs/SPEC.md`](docs/SPEC.md)
>
> 개발 진행 상황: [`ROADMAP.md`](ROADMAP.md)

## 게임 특징

- 11개 지역을 이동하는 데이터 기반 횡스크롤 월드
- Lv.9 초보자부터 Lv.200까지 이어지는 성장과 4단계 전직
- 기본 표창 공격, 액티브 스킬 11종, 패시브 스킬 4종
- 아이콘 문양과 연결된 시전 예고, 투사체 잔상, 화면장, 다단 충격파 연출
- 일반 몬스터, 중간·상위·최종 보스와 순차 원정 퀘스트
- 24칸 인벤토리, 6등급 표창, 상점, AP·SP 분배와 단축키 편집
- 자동 회수 펫 두아와 최초 1회 보상을 제공하는 인내의 숲
- PC 키보드와 모바일 터치 조작, 접근 가능한 DOM 메뉴
- 브라우저 `localStorage`를 사용하는 캐릭터별 3개 독립 저장 슬롯

## 설치 및 실행

저장소 루트에서 다음 명령을 실행합니다.

```bash
npm ci
npm run dev
```

Vite가 터미널에 표시한 로컬 주소(기본값은 보통 `http://localhost:5173`)를 브라우저에서 엽니다.
첫 화면에서 `게임 시작`을 선택한 다음, 비어 있지 않은 아이디와 비밀번호를 입력하면 캐릭터 생성으로
이동합니다.

로그인은 로컬 게임 진입 절차일 뿐 실제 인증이 아닙니다. 입력값은 외부 서버로 전송되지 않으며
비밀번호도 저장하지 않습니다.

### 프로덕션 빌드 확인

```bash
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. `npm run preview`가 출력한 주소에서 실제 배포 번들을 확인할 수
있습니다.

## 게임 시작 안내

첫 캐릭터는 다음 두 방식 중 하나로 만들 수 있습니다.

- 일반 시작: Lv.9 초보자로 시작해 전직 시험과 사냥을 순서대로 진행합니다.
- 빠른 체험: 생성 화면에서 Lv.120 호카게 부스트를 선택해 상위 스킬과 보스 구간을 확인합니다.

일반적인 진행 흐름은 다음과 같습니다.

1. 커닝시티에서 캐릭터를 생성하고 현재 목표를 확인합니다.
2. 사냥으로 레벨을 올리고 Lv.10·30·60·120 전직 시험을 완료합니다.
3. 획득한 AP와 SP를 능력치와 스킬에 배분하고 더 강한 표창을 장착합니다.
4. Lv.100부터 보스 원정을 수락해 중간보스, 상위보스, 최종보스를 순서대로 처치합니다.
5. 별도 도전 지역인 인내의 숲 정상에서 최초 1회 보상을 획득합니다.

## 조작법

### PC 키보드

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 좌우 이동, 줄에서 이탈 |
| `↑` | 포탈·NPC 상호작용, 줄 올라가기 |
| `↓` | 줄 내려가기 |
| `Alt` | 점프, 줄에서 이탈 |
| `↓ + Alt` | 현재 단방향 발판 아래로 내려가기 |
| `Ctrl` | 기본 표창 공격, 구미호 변신 중 할퀴기 |
| `1~0`, `-` | 편집 가능한 액티브 스킬 11칸 |
| `Shift`, `QWER`, `ASDF`, `XCV` | 비우거나 중복 지정할 수 있는 추가 스킬 키 |
| `B` / `N` | 구미호 변신 / 삼인 협공 고정 보조키 |
| `Z` | 범위 안에서 가장 가까운 전리품 회수 |
| `I` | 인벤토리 |
| `K` | 스킬과 SP 분배 |
| `S` | 추가 스킬이 비어 있을 때 능력치·표창 장비 창 |
| `Esc` | 전체 메뉴 열기 또는 현재 팝업 닫기 |

게임 Canvas(실제 게임 화면)에 포커스가 있을 때만 게임 키가 동작합니다. 메뉴를 닫으면 Canvas로
포커스가 자동 복구됩니다.

### 모바일·태블릿

- 좌하단 조이스틱: 좌우 이동과 아래 입력
- 우하단 고정 버튼: 점프, 공격, 줍기
- 상황별 버튼: NPC 근처의 `대화`, 포탈·줄 근처의 `이동`
- 대표 스킬: 현재 직업에 맞는 액티브 스킬 최대 4개
- 우상단 `MENU`: PC의 `Esc`와 같은 전체 메뉴

세로 화면은 safe-area(노치와 홈 표시 영역을 피하는 안전 여백)를 적용하며, 긴 메뉴는 화면 안에서
독립적으로 스크롤됩니다.

## 주요 시스템

### 성장과 전직

- 최대 레벨은 200입니다.
- 레벨업마다 최대 HP·MP, AP 5, SP 3을 받고 HP와 MP가 완전히 회복됩니다.
- 전직은 Lv.10 로그, Lv.30 어쌔신, Lv.60 허밋, Lv.120 호카게 순서입니다.
- 전직 시험은 항상 `수락 → 지정 몬스터 처치 → NPC에게 완료 보고` 순서로 진행됩니다.

### 전투와 스킬

- 피해량은 능력치, 스킬 레벨, 장착 표창과 몬스터 방어를 반영합니다.
- 고급 스킬 7종은 `짧은 시전 문양 → 화면장과 이동 잔상 → 2~3단 명중 파동`으로 연출됩니다.
- 화면 전체 효과는 플레이 영역에만 나타나며 하단 124px 스킬 HUD를 가리지 않습니다.
- 임시 투사체, 타이머와 이펙트는 맵 이동이나 Scene 종료 시 함께 정리됩니다.

### 음악과 효과음

- 일반 지역에서는 중간 템포의 `달빛 골목의 여행자`, 살아 있는 보스가 있는 지역에서는 빠른 `심연의 맥동`을 재생합니다.
- 두 곡 모두 외부 음원 샘플 없이 Web Audio 오실레이터로 리드·베이스·패드·킥을 실시간 합성합니다.
- 브라우저 정책에 따라 첫 키보드·터치 입력 뒤 음악이 시작되며, 메뉴에서 음소거와 BGM/SFX 음량을 각각 저장할 수 있습니다.
- 공격·스킬·명중·치명타·처치·회수·포탈·피격·부활·레벨업·메뉴·보스 효과음 12종이 실제 사건에 연결됩니다.

### 저장과 개인정보

- 캐릭터는 브라우저 origin(주소 단위 저장 공간)별로 최대 3개 슬롯에 저장됩니다.
- 닉네임, 성장, 장비, 인벤토리, 스킬, 퀘스트와 11개 맵 위치가 슬롯별로 분리됩니다.
- 저장 형식은 현재 v16이며 이전 저장값은 가능한 범위에서 자동 이관됩니다.
- 오디오 설정은 캐릭터 슬롯과 별도로 저장됩니다.
- 저장을 초기화하려면 브라우저 개발자 도구의 Application/Storage에서 이 사이트의
  `localStorage`를 삭제합니다. 이 작업은 복구할 수 없으므로 필요한 캐릭터가 없는지 먼저 확인하세요.

## 기술 사양

| 구분 | 사양 |
| --- | --- |
| 언어·빌드 | TypeScript 5, Vite 7 |
| 게임 엔진 | Phaser 3.90, Arcade Physics |
| UI | Phaser Canvas + 접근 가능한 DOM/CSS 오버레이 |
| 논리 해상도 | 1280×720, 종횡비 유지 `FIT` |
| 플레이 영역 | y=0~596, 하단 HUD 124px 분리 |
| 월드 | 11개 맵, 일반 맵 1920×720 중심, 인내의 숲 1920×1440 |
| 물리 | 중력 y=1250, 고정 스텝 |
| 저장 | 서버 없는 브라우저 `localStorage`, 최대 3슬롯 |
| 테스트 | Vitest 단위 테스트, Playwright Chromium·Firefox·WebKit E2E |
| 배포 에셋 | Vite로 번들된 로컬 WebP·폰트·오디오, 플레이 중 외부 네트워크 의존 없음 |
| 성능 목표 | 60 FPS, 자동화 루프 종료 시 50 FPS 이상 |

지원 대상은 최신 Windows Chrome·Edge·Firefox, macOS Chrome·Firefox·Safari와 최신 터치
브라우저입니다. 게임패드, 네이티브 앱, 멀티플레이와 계정 서버는 현재 범위에 포함되지 않습니다.

## 개발 명령

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | Vite 개발 서버 실행 |
| `npm run typecheck` | TypeScript strict 타입 검사 |
| `npm test` | Vitest 단위 테스트 1회 실행 |
| `npm run test:coverage` | 단위 테스트와 V8 커버리지 리포트 생성 |
| `npm run build` | 타입 검사 후 프로덕션 번들 생성 |
| `npm run preview` | 생성된 `dist/` 로컬 미리보기 |
| `npm run test:e2e` | 프로덕션 번들을 3개 브라우저로 E2E 검증 |
| `npm run release:check` | 번들 용량과 금지 파일을 포함한 `dist/` 감사 |
| `npm run release:check -- --release` | 크레딧·라이선스 동봉까지 확인하는 최종 릴리스 감사 |

Playwright 브라우저가 설치되지 않은 개발 환경에서는 최초 한 번 다음 명령이 필요합니다.

```bash
npx playwright install chromium firefox webkit
```

권장 전체 검사 순서는 다음과 같습니다.

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run release:check
```

현재 릴리스 예산은 BGM을 제외한 총량 8,000,000 bytes, JavaScript 1,500,000 bytes,
JavaScript gzip 450,000 bytes입니다.

## 프로젝트 구조

```text
src/game/
  scenes/        화면 흐름과 Gameplay 런타임
  maps/          맵·발판·줄·포탈·스폰 데이터와 규칙
  entities/      플레이어·몬스터·카메라 엔티티
  combat/        공격·피해·보스 전투 규칙
  progression/   EXP·레벨·회복·AP 규칙
  skills/        액티브·패시브·SP·단축키 규칙
  inventory/     소모품과 부활 아이템 규칙
  pets/          두아 추적과 자동 회수 규칙
  quests/        전직·보스·인내의 숲 상태 머신
  profile/       캐릭터 저장, 파서와 마이그레이션
  effects/       스킬·포탈·전직·레벨업 연출
  audio/         BGM·SFX 정의와 수명주기
  ui/            HUD·DOM 메뉴·미니맵·반응형 경계
  assets/        런타임 에셋 URL과 매니페스트
assets/          생성 원본·제작 기록·런타임 에셋
tests/unit/      순수 규칙 단위 테스트
tests/e2e/       실제 브라우저 핵심 플레이 흐름
scripts/         에셋·릴리스 검사 도구
docs/            최종 제품 명세
```

수치와 조건의 단일 기준은 Scene이나 UI 문자열이 아니라 각 도메인의 데이터·순수 규칙 모듈입니다.
구현을 변경할 때는 관련 테스트와 [`docs/SPEC.md`](docs/SPEC.md)를 함께 갱신해야 합니다.

## 에셋과 권리

게임의 런타임 에셋은 직접 제작, 생성형 도구 제작 또는 배포 권리가 확인된 자료만 사용합니다.
참고 작품의 코드, 지도, UI, 음원, 캐릭터, 아이콘과 고유 문양은 복제하지 않습니다.

- 제작자·원본·변환·라이선스 기록: [`ASSET_CREDITS.md`](ASSET_CREDITS.md)
- 에셋 규격과 감사 기준: [`ASSET_GUIDE.md`](ASSET_GUIDE.md)

생성 원본과 제작 기록은 보존하지만 최종 `dist/`에는 최적화한 런타임 파생본만 포함합니다.
